# ADR-002 · 默认 Lite 与 v4 兼容边界

- 日期：2026-09-26；状态：accepted（负责人已一次裁决，尚未发版）。
- 决策：一个项目运行时脚本承载四个子命令；按实际 tools 接线，铭牌只记录版本/档位/日期/工具。方法论仍只有 CORE。
- 默认退出：施工许可、发现/升级常驻、需求制度、认领/周报/registry、空 ADR/架构模板、仓外事实库与判例安装。母版按需 CLI 和历史数据保留。
- 替代：短宪法正本表、带日期游标与决策；五类危险命令；真实扫描器 fail-closed；暂存区仓外绝对路径软链硬门。软链门替换施工许可门，来源为负责人提供的微信客服 INC-031（停摆 19 分钟）。
- 兼容：Standard/High Assurance 与 v4 模板冻结旧安装接口，保持原正反回归；不作为另一套持续演化的方法论。
- 原因：避免默认安装 49 个文件/4345 行的长期成本，同时可逆迁移、保留项目事实与存量恢复能力。
- 回滚：逐提交反向恢复本分支；消费项目未改动。迁移在独立 worktree 保存恢复点、合并接线、验证后采用，失败回退。
- 验收：自动检查、事故重放与指标见施工审计；独立无上下文考试由主控安排，不以本地自动化代证。
