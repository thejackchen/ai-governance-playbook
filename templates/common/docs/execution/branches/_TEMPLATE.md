## 事实与边界

> 判决记录区：一行结论 + 一个出处指针。已验事实、防误宣称边界（【边界】开头，天然免证据指针）、判废禁令、验收指针都住这里；叙述与过程进 evidence/ 或 git 历史，不进正本。

- 已验事实一条一行，带证据指针（链接或提交号）。
- 【边界】还没成的事、不许宣称的话、已判废不得回流的方案。
- 验收指针：→ 指向 evidence/模块页/ROADMAP 的出处。
