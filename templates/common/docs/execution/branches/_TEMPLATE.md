# 战线 · {{BRANCH_SLUG}}

> 一条战线的完整叙事：新人只读本文件即可零上下文接管这条战线。状态唯一可写处＝「当前游标」；ROADMAP 战线表是它的机器投影，不在别处另记状态。
>
> 何时需要本文件：并行推进的独立战线 ≥ 3、单张 ROADMAP 战线表压不住叙事时，才把每条战线毕业成一个本文件。战线 < 3 的项目留在 `ROADMAP.md` 单表即可，别预装（奥卡姆）。
